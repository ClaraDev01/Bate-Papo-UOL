# 💬 Bate-Papo UOL

A real-time chat application inspired by the classic Bate-Papo UOL. Built with JavaScript, HTML and CSS — no libraries used. Mobile version only.

## 🚀 Live Demo

🔗 [Open Chat](https://bate-papo-uol.vercel.app)

## ✨ Features

- 💬 Enter a username and join the chat room instantly
- 📩 Send public messages to everyone or private messages to specific users
- 🔒 Toggle between public and private (reserved) messages
- 👥 View active participants in a side menu
- 🔄 Chat auto-updates every 3 seconds
- 🟢 Connection kept alive every 5 seconds automatically
- 🎨 3 message types: status (gray), public (white) and private (pink)
- 📱 Mobile-first design

## 🎯 How to Use

1. Open the app and enter your username
2. Start chatting with everyone in the room
3. Click the participants icon to open the side menu
4. Choose a specific contact to send a private message
5. Toggle between public and private visibility

## 💻 How to Run Locally

```
git clone https://github.com/ClaraDev01/Bate-Papo-UOL.git
```

Then open `index.html` in your browser — no installation needed!
